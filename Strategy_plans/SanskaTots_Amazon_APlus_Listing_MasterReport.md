## 0. EXECUTIVE SUMMARY — WHAT MAKES A "TOP-NOTCH" AMAZON LISTING IN 2026

Amazon India's algorithm in 2026 rewards listings that simultaneously:
1. **Convert** (high CTR + high CVR) — driven by Main Image, Title, Price, Reviews
2. **Engage** (long dwell time on PDP) — driven by A+ Premium modules, video, comparison chart
3. **Rank** (organic SEO) — driven by indexed keywords in Title, Bullets, Backend Search Terms, A+ ALT text
4. **Retain** (low return rate) — driven by accurate imagery, dimension clarity, age-appropriateness signals

Our entire 7-book strategy is built around these four pillars. Every image, every keyword, every bullet has a job.

**Target benchmark for SanskaTots Phase 1:**
- Main image CTR: **0.45%+** (category avg 0.28%)
- PDP conversion: **18–22%** (category avg 11%)
- Organic Page-1 ranking on **3 head keywords per SKU within 90 days**
- Return rate: **<3%** (category avg 6–8%)

## 1. UNIVERSAL AMAZON IMAGE STACK (Applies to ALL 7 Books)

Amazon allows up to **9 image slots** (7 visible + 2 hidden) + 1 video. Use **all of them**. Empty slots = lost conversion.

### 1.1 The 9-Slot Image Framework

| Slot | Purpose | Background | Text Overlay? | Critical Rule |
|------|---------|------------|---------------|----------------|

- **File naming:** `ASIN_01_main.jpg`, `ASIN_02_lifestyle.jpg` etc. (Amazon indexes filenames)
- **ALT text:** Always fill ALT text in A+ modules with primary + LSI keywords
- **Mobile-first design:** 79% of Amazon India traffic is mobile — text must be legible at 350px width

## 2. AMAZON A+ CONTENT (EBC) — UNIVERSAL MODULE BLUEPRINT

A+ Content gives you the **PDP description area** (replaces plain text). For Brand Registered sellers (which SanskaTots must be), aim for **A+ Premium** (formerly A++) which adds video modules + interactive hotspots.

### 2.1 Recommended A+ Module Stack (per SKU)

```
[Module 1] Brand Story Header         → Cinematic hero image + tagline
[Module 2] Standard Image + Light Text → Problem statement (e.g., "Too much screen time?")
[Module 3] 4-Image with Text          → 4 key features as cards
[Module 4] Standard Image Header      → "How it works" demo (Velcro books)
[Module 5] Comparison Chart           → SanskaTots vs other books in catalog (cross-sell!)
[Module 6] Image + Dark Overlay       → Age & skills mapping
[Module 7] Single Large Image         → Full-bleed lifestyle shot
[Module 8] FAQ / Brand Trust          → 4-5 FAQs answered visually
```

### 2.2 A+ Content Writing Rules

1. Every text block must contain **at least 1 indexed keyword** from your backend search terms
2. ALT text on every image is **searchable** — never leave it blank
3. Use **<150 characters per text block** on mobile-visible modules
4. Comparison chart MUST include all 7 SanskaTots SKUs to drive cross-purchase

### 3.2 Backend Search Terms Rules

- 250 bytes max (NOT 250 characters — Indian language characters cost more bytes)
- No competitor brand names (Amazon may suppress listing)
- No subjective claims ("best", "top")
- Include **misspellings** (e.g., "bhagwat geeta", "shlok", "kanada")
- Include **regional spellings** (e.g., "ಕನ್ನಡ" + romanized "kannada")
- Include **gift intent** keywords (return gift, birthday gift, naming ceremony gift)
