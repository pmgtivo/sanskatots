# CONTENT RULES — NON-NEGOTIABLE

| Rule | Why |
|---|---|
| Never fake reactions | Indian moms can smell inauthenticity from 10 km away |
| Always show the product in use | Pretty covers don't sell. Usage sells. |
| Use Indian English naturally | "na", "matlab", "basically" — the way we actually talk |
| Include regional language hooks | Kannada/Hindi text on screen gets shared in regional WhatsApp groups |
| Keep hooks under 3 seconds | If you don't grab in 3 sec, they scroll |
| End every reel with ONE clear CTA | Not 5 things. ONE thing to do. |
| Post between 7–9 AM or 8–10 PM | Indian mom Instagram hours (before kids wake / after kids sleep) |
| Respond to EVERY comment for first 30 min | Algorithm reward for engagement velocity |
