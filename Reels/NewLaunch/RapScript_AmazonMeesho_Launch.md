## 📝 Production Notes

| Element | Direction |
|---|---|
| **Beat style** | Desi hip-hop / upbeat trap — think Raftaar energy or a fun Bollywood rap beat. Use a royalty-free track or trending Instagram audio |
| **Performer** | Founder on camera rapping = maximum authenticity. Or use animated text on beat if camera-shy |
| **Opening shot** | 3-second silent pause with book cover, then beat drops — creates pattern interrupt |
| **Verse 1 visuals** | Real footage of child with phone → dramatic reaction when phone is taken |
| **Chorus visuals** | Fast-cut montage: book pages, velcro rip, Amazon/Meesho app screenshots, India map |
| **Bridge lighting** | Slightly warmer tone — feels emotional, not commercial |
| **Final chorus** | Most energetic visuals — all 7 books in frame, confetti/celebration vibe optional |
| **Subtitles** | Add rap lyrics as on-screen captions — accessibility + retention booster |
| **Duration** | Full version: ~55 seconds. Short version: Verse 1 + Chorus + Final Chorus = ~30 seconds |
